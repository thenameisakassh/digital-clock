# ⏰ Digital Clock Web App

A simple and responsive digital clock built using HTML, CSS, and JavaScript.  
This project displays the current time and updates every second in real-time.

## 🚀 Features
- Live digital clock
- Updates every second
- Clean and modern UI
- Beginner-friendly JavaScript project
- Responsive design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (DOM + setInterval)

## 📂 Project Structure
digital-clock/
│── index.html
│── style.css
│── script.js

## ▶️ How It Works
- Uses JavaScript Date object to get current time
- setInterval() updates time every second
- DOM manipulation used to display time on screen
